## 当前命题

企业 AI 治理正在从“模型是否安全”扩展到“Agent 是否能在组织权限、数据边界、审计要求和失败恢复中运行”。治理不再是合规部门的后置问题，而是产品能否部署的前置条件。

## 最新变化

- Agent 产品开始强调权限、日志、审计和人工接管。
- 企业采购会要求更可解释的任务执行路径。
- Eval 需要覆盖业务流程，而不是只覆盖模型回答。

## 关键实体

Microsoft、OpenAI、Anthropic、Google DeepMind。

## 重要声明

- 企业采用 Agent 的瓶颈会从性能转向可验证性。
- 身份、权限和审计系统会成为企业 Agent 平台的结构性优势。
- 缺乏失败恢复能力的 Agent 难以进入核心流程。

早期企业 AI 关注数据安全和模型输出风险；Agent 出现后，治理对象扩展到任务执行、权限调用、跨系统操作和责任链。
