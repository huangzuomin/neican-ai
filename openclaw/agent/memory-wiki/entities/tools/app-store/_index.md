# App Store

**角色**: 披露付费版本声明的平台

## 关联事件 (1)

- 2026-05-04: 豆包宣布推出付费订阅服务，三档月包/年包价格曝光

## 结构化声明 (4)

- 豆包App Store页面出现付费版本服务声明，披露了三档订阅价格：标准版连续包月68元（连续包年688元）、加强版连续包月200元（连续包年2048元）、专业版连续包月500元（连续包年5088元）。（95%）
- 豆包官方回应称，付费方案细节目前还在测试阶段，正式上线时会通过官方渠道发布完整信息。（95%）
- 据接近豆包的人士透露，付费功能将主要专注在复杂任务和生产力场景，如PPT生成、数据分析、影视制作。（85%）
- 免费版本继续面向用户的日常使用。（90%）
