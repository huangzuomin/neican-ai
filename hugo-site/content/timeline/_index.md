<section id="agent-enterprise" class="timeline-focus">
  <p class="section-label">当前展开</p>
  <h2>AI Agents 如何从聊天助手演化为企业工作流基础设施</h2>
  <p>这条线追踪的不是单个产品发布，而是 Agent 被企业真正采用前必须补齐的能力：工具连接、权限边界、运行时治理、失败恢复和可评测性。</p>
</section>

<div class="timeline-board">
  <section>
    <time>2024</time>
    <div>
      <h2>工具调用成为模型产品标配</h2>
      <p>模型厂商开始把函数调用、长上下文和多步推理包装成产品能力。Agent 的雏形从“会聊天”转向“能接工具”。</p>
      <p class="node-meta"><span>关联：OpenAI</span><span>主题：AI Agents</span><span>影响：能力边界外扩</span></p>
    </div>
  </section>
  <section>
    <time>2025</time>
    <div>
      <h2>开发者工具验证 Agent 工作流</h2>
      <p>代码编辑、终端操作、文档检索和版本回滚让开发者场景成为最早成熟的 Agent 试验场。Cursor 等产品让任务闭环更加可见。</p>
      <p class="node-meta"><span>关联：Cursor</span><span>主题：开发者工具</span><span>影响：任务闭环可见</span></p>
    </div>
  </section>
  <section>
    <time>2025</time>
    <div>
      <h2>MCP 让连接层升温</h2>
      <p>MCP 把 Agent 集成从单个插件推向协议层。工具、上下文和服务端生态开始成为模型之外的新竞争点。</p>
      <p class="node-meta"><span>关联：Anthropic</span><span>主题：MCP</span><span>影响：连接层平台化</span></p>
    </div>
  </section>
  <section>
    <time>2026</time>
    <div>
      <h2>企业治理成为采用门槛</h2>
      <p>Agent 要进入核心流程，必须回答权限、审计、失败恢复、人工接管和数据边界问题。运行时治理成为企业 AI 的控制平面。</p>
      <p class="node-meta"><span>关联：Microsoft</span><span>主题：企业 AI 治理</span><span>影响：采购语言变化</span></p>
    </div>
  </section>
  <section>
    <time>下一步</time>
    <div>
      <h2>Eval 从模型指标扩展到任务风险</h2>
      <p>企业会要求 Agent 在真实权限和数据环境中证明任务成功率、恢复能力和可解释性。评测将成为采购和部署的重要语言。</p>
      <p class="node-meta"><span>关联：OpenAI / Anthropic</span><span>主题：Eval</span><span>影响：部署门槛提高</span></p>
    </div>
  </section>
</div>
