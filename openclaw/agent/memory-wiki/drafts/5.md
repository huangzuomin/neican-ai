# 上海大航跃迁完成5亿元融资，推进国内首款塔架回收火箭研制

上海大航跃迁航天科技有限公司完成5亿元融资，用于研制国内首款采用“筷子夹”塔架回收技术的运载火箭“跃迁一号”，计划2027年首飞。公司是国内首家落地该技术的二代民营火箭企业，本轮融资由多家机构领投，资金将用于火箭研制及液氧甲烷发动机研发。
