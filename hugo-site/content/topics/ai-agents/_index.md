## 当前命题

AI Agents 的核心变化是从“模型能完成任务”转向“系统能否稳定、可控、可审计地执行任务”。这让运行时、权限、工具连接和评测成为与模型能力同等重要的变量。

## 最新变化

- Agent Runtime 开始成为企业产品的控制平面。
- 开发者工具先形成高频、可验证的 Agent 工作流。
- 企业客户开始追问任务日志、失败恢复和人工接管。

## 关键实体

OpenAI、Anthropic、Microsoft、Google DeepMind、Cursor。

## 重要声明

- Agent 产品的上限取决于运行时治理，而不只是模型能力。
- 开发者场景会先验证 Agent 工作流，再外溢到更宽的企业场景。
- Eval 会从模型指标扩展到端到端任务成功率。
