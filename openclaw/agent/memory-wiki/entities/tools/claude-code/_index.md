- The leaked Claude.md describes a dual-backend system: Juno AI for auto-responses and Live Agents for human takeover, with seamless switching via a Protocol layer.（90%）
- Apple runs a custom Claude model on its own servers for internal development, keeping code and data within Apple's infrastructure.（85%）
- Apple has partnered with Google to replace old Siri with Gemini, but for internal development tools it chose Claude over Gemini.（80%）
- The leak was discovered by MacRumors analyst Aaron Perris.（95%）

- 苹果客服系统采用双后端架构：Juno AI负责自动应答，Live Agents负责真人客服接管，通过Protocol协议层无缝切换。（85%）
- 苹果在24小时内紧急撤回了该版本。（90%）
- 彭博社记者Mark Gurman曾报道苹果在自家服务器上运行定制版Claude模型。（80%）
- 苹果在Apple Support应用v5.13版本中意外将Claude.md文件打包进发布版本。（95%）
- 苹果内部使用Claude Code构建生产级应用，泄露的Claude.md文件描述了双后端对话系统架构。（90%）
- 泄露的对话系统采用Juno AI自动应答和Live Agents真人客服两套后端，通过Protocol协议层无缝切换。（85%）
- 系统消息设计包含client、agent和assistant三种角色，但未向用户提示消息来源是AI还是人类。（85%）
- 苹果在24小时内紧急撤回了该版本更新。（90%）
- 彭博社记者Mark Gurman此前报道苹果在自家服务器上运行定制版Claude模型。（80%）
