## 当前命题

MCP 的意义不只是给 Agent 多接几个工具，而是把工具、上下文和外部系统连接成可复用的协议层。它可能改变开发者工具、企业软件和模型平台之间的生态边界。

## 最新变化

- 开发者工具成为 MCP 的早期验证场。
- 工具连接从单个插件变成可复用服务端生态。
- 企业采用 MCP 时会自然引入权限和审计问题。

## 关键实体

Anthropic、Cursor、Microsoft。

## 重要声明

- MCP 的战略价值在于把 Agent 的工具连接层标准化。
- 连接层协议会影响 Agent 生态入口和开发者分发路径。
- MCP 能否进入企业软件，取决于权限、数据边界和安全审核。
